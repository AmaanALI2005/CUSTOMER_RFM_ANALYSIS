## 🎯 Project Objective

The objective of this project is to segment customers using RFM analysis and turn transaction data into useful business insights. RFM is based on three dimensions:

- **Recency:** How recently a customer made a purchase.
- **Frequency:** How often a customer makes purchases.
- **Monetary:** How much a customer spends.

## 📌 Dashboard Features

- Total customer and revenue KPIs
- Average customer value
- Revenue trend by year
- Monthly customer trend
- Country-level analysis
- Product revenue analysis
- RFM customer segmentation
- Interactive filters for month, quarter, year, country, and segment

## 🚀 How to Open the Project

1. Download `RFM_Analysis_Dashboard.pbix` from this repository.
2. Open the file in **Microsoft Power BI Desktop**.
3. Explore the report pages.
4. Use the slicers to filter the dashboard by month, quarter, year, country, and customer segment.
